# Abstract

帝制时期的中国家谱（*jiapu*，家谱）保存了关于父系血脉的详尽记录，却系统性地抹去了女性的身影：妻子的身份大多止步于一个姓氏，女儿的记录则在其本宗那一支戛然而止。家谱中婚姻边（marriage edges）的结构性缺失遮蔽了母系亲属网络 —— 即 *muxia*（母家，"mother's house"）—— 而这一网络在晚期帝制政治中的作用虽有充分的史学记录，却在量化层面长期研究不足。我们提出 **[SYSTEM]**，一个 visual analytics workspace，将家谱补全视为一项 *interpretable link-prediction* 任务：由一个 heterogeneous graph transformer (HGT) 提出候选婚姻，再由一个 LLM 驱动的 multi-agent negotiation 在历史学家可注入的约束下重新审议每一项提议。由于没有任何家谱语料能自带真值（ground truth），我们改用 CMGPD-LN 人口面板 —— 一份独立于家谱的清代资料，由辽宁的旗人三年一造户口册编制而成，保留了家谱所压制的婚姻边与母系边 —— 作为评测测试平台：我们消融（ablate）其 $r_{hw}$ 与 $r_{md}/r_{ms}$ 边以模拟家谱式的记录缺口，再将重建结果对照保留下来的边进行打分。在 131,140 对保留测试对上，仅 HGT 层即可达到 Hungarian recall@1 = 0.625、Hit@5 = 0.534（ROC-AUC = 0.99），但*无约束*的 Hit@1 仅为 0.325 —— 远低于史学家提交阈值；[SYSTEM] 通过将低置信度案例路由至一轮六回合、双向、由 persona 锚定的 negotiation 来弥合残余差距，操作员在 1882 年保留队列上经 V4-batch 路径的 acceptance precision 校准为 ≈0.87（该队列上 HGT Hungarian recall@1 = 0.784），同时保留一份 audit trail，使每一次提交都对齐到一个或多个 SEAL motif、以及（如有）稀疏的档案线索。三项分别由人口史家、家谱学家与清代政治史家参与的案例研究表明，[SYSTEM] 将一个不透明的 GNN ranking 转化为一种审议式工作流，其中每一条被接受的边都由图上的某种 pattern、agent transcript 中的某段叙事、或两者共同来佐证 —— 这正是评测测试平台所认证、而家谱部署场景所必需的工作流。
