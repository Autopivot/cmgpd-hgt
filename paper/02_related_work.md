# 2 Related Work

**Visual analytics for relational and historical archives.** Network-completion visualisations for biographical or historical data have long combined edge-uncertainty cues with mixed-initiative exploration. Earlier systems for prosopographical archives surfaced co-occurrence and temporal-flow signals [vis-prosopography], while more recent work has treated link prediction as the analytic primitive and examined how analysts react to model confidence [vis-link-prediction-confidence]. **[SYSTEM]** extends this tradition along two axes: it commits explicitly to GNN-based ranking as the surface from which to begin exploration, and it treats the LLM agent transcript as a first-class evidence layer rather than as an external explanation tool.

**Heterogeneous graph learning and link prediction.** Heterogeneous graph transformers [hu2020hgt] extended attention across typed relations and remain a competitive baseline for multi-relational link prediction. Closed-loop labelling subgraph methods — SEAL [zhang2018seal] and its extensions — expose the local structural pattern that motivates a prediction. We use both as backbone, but our contribution is not architectural; rather, we treat their outputs as the *priors* that an LLM-based agent population will then deliberate over.

**LLM agents and multi-agent simulation.** Recent work has framed LLM-based agents as deliberative units [park2023generative], with negotiation and preference-elicitation protocols that surface persona-grounded reasoning [abdelnabi2023negotiation]. We build on this line but specialise it: agents are seeded by life-history evidence drawn from DS0003 (events from `EVENT_1/2`, income from `ESTIMATED_INCOME`) and seeded with HGT pre-scores and SEAL motif tags, so that each round has both narrative and structural provenance.

**Mixed-initiative and human-in-the-loop systems.** Hint-driven steering and human-in-the-loop correction has a deep tradition in visual analytics [endert2014mixed]. [SYSTEM]'s hint console (`@everyone`, `@target`, `@c-XX`) draws on this lineage and operationalises it as system messages drained between rounds; this lets historians inject brittle archival evidence (a surviving surname, a banner constraint) without breaking the agent loop.
