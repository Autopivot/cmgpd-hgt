# 11 Conclusion

**[SYSTEM]** reframes genealogical marriage-edge reconstruction as a collaborative analytic process between an HGT link-prediction backbone, a SEAL motif-grounded LLM agent population, and a historian whose archival hints are first-class inputs to the loop. By making provenance, narrative, and reversibility constitutive of every commit — not after-the-fact explanations — [SYSTEM] provides a workspace in which low-confidence GNN rankings become defensible reconstructions. We validate on CMGPD-LN, a Qing triennial administrative panel whose ablation harness lets each design decision be graded against ground truth; the deployment target is real Chinese family genealogies (jiapu, 家谱), where ground truth is unavailable but the female-record gap is the actual problem [SYSTEM] is built around. The system generalises in the direction that matters: a workspace whose every artefact remains interpretable to the historian who must vouch for the finished tree.
